A Python-based project focused on analyzing Istanbul public transportation data, including bus stops, routes, and transportation-related indicators. The project explores stop locations and develops a relative priority index from available dataset characteristics.
- **Technologies:** Python, Pandas, Folium, CSV, OpenStreetMap
- **Highlights:** Transportation data processing, stop analysis, and interactive map visualization
- **Repository:** [View IETT Transport Data Analysis](https://github.com/mertortatepe3121-cell/IETT-Transport-Data-Analysis)
### 📊 IETT Transport Dashboard
A Flask-based web application that organizes public transportation data into dashboard panels, tables, and analysis views using available IETT and Istanbul Metropolitan Municipality data sources.
- **Technologies:** Python, Flask, HTML, CSS, JavaScript
- **Highlights:** Dashboard panels, data tables, transport information, and data analysis
- **Repository:** [View IETT Transport Dashboard](https://github.com/mertortatepe3121-cell/IETT-Transport-Dashboard)
